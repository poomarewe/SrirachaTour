Huninn is downloaded from Google Fonts and served locally for the loading-screen title.

Source: https://github.com/google/fonts/tree/main/ofl/huninn
Download: https://fonts.googleapis.com/css2?family=Huninn&text=Sriracha%20Express

Huninn-SrirachaExpress.ttf contains the glyphs for “Sriracha Express” only, keeping the initial download small. Request a new subset if this title changes. The original font name and SIL Open Font License are preserved; see Huninn-OFL.txt.
